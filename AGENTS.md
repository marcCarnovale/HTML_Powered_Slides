# Public Portfolio Engineering Rules

- Correctness, reproducibility, restraint, and honest claims matter more than feature count.
- Inspect before editing and protect behavioral changes with tests.
- Never invent performance figures, capabilities, users, screenshots, or scientific results.
- Do not add frameworks or dependencies without a concrete need.
- Do not commit caches, generated output, credentials, or machine-specific state.
- Run the relevant tests and a clean-install smoke test; report exact commands and failures.
- Keep the README synchronized with executable behavior and state limitations explicitly.
